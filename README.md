# 跨境电商选品分析

> 来源分类：**待确认** ｜ 导出批次：review

自动爬取跨境电商平台榜单、智能计算利润、排查侵权风险、分析竞品与市场机会，一键生成专业完整的选品决策报告

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/cross-border-ecommerce-product-analysis        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/cross-border-ecommerce-product-analysis   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
